S1-4 · Memorization vs generalization, and data closes the gap

One over-parameterized network, three dataset sizes. The only thing that changes below is how much data the model gets.

The task has irreducible noise: two overlapping point clouds, so even a perfect model tops out near ~88% on held-out data. A network with over a thousand parameters given only 20 examples does something cheaper than learning the rule — it memorizes: train loss crashes to zero while held-out loss climbs. Give the very same network 2000 examples and memorizing stops being cheap; the honest rule is now the easiest thing to learn, and the gap closes. Data is the regularizer.

Two Gaussian classes with heavy overlap (Bayes-optimal ≈ 88%), a fixed held-out set of 500 points, and three copies of a 2→32→32→1 ReLU network trained by minibatch SGD (batch 64, lr 0.3, logistic loss, default 3000 steps). Train points are drawn on each map; the held-out points are never shown to the models. Watch n=20: the boundary grows islands around individual points, train hits 100%, and the held-out curve rises while train loss falls — that is memorization. More width (slider) makes the small-data gap worse, more data makes it vanish.
