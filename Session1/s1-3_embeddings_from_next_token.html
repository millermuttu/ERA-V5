S1-3 · Embeddings learn similarity from nothing but next-token

A tiny language, a tiny model, one objective: guess the next token. Nobody ever says which words are alike.

The model below is just an embedding table and a softmax: look up the current token’s vector, predict the next token. The training data never labels categories — it is only sentences. But cat, dog, cow appear in the same slots, so they need the same predictions, and the cheapest way to give identical predictions is identical embeddings. Similarity falls out of the objective; it was never supplied.

Vocabulary of 9 tokens, ~200 three-word sentences (ANIMAL VERB OBJECT), full-batch gradient descent on next-token cross-entropy, learning rate 0.5, default 2000 steps.
