Session 1 — why networks are built the way they are
S1-1

Activations exist for a reason

A model with no nonlinearity can only draw a straight boundary, so it can never separate a ring inside a ring. One ReLU hidden layer wraps it.

Proof: two boundary maps — a stuck straight line vs a closed curve, ~55% vs ~99%. S1-2

Depth without nonlinearity is a lie

Five stacked linear layers collapse to a single matrix, so they tie with one layer exactly — until ReLU between the same five layers breaks the tie.

Proof: multiply the five trained matrices live — max difference 0.000 vs the 1-layer model. S1-3

Embeddings learn similarity from nothing but next-token

Trained only to predict the next token of a toy language, the embedding table clusters animals, fruits, and verbs — similarity was never supplied.

Proof: live PCA scatter + cosine heatmap — 9/9 nearest neighbors same-category. S1-4

Memorization vs generalization, and data closes the gap

An over-parameterized net on 20 examples drives train loss to zero while held-out loss climbs; the same net on 2000 examples can no longer cheat.

Proof: generalization-gap bars at n = 20 / 200 / 2000 — huge → small → ~zero.
