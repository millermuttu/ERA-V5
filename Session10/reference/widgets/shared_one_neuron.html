One neuron: weighted sum, then squish

Multiply each input by a weight, add them up, add a bias. That is y = w·x + b. Then pass it through the squish. That last step is the only non-linear thing here.

The squish (activation)
The weighted sum z = w₁·x₁ + w₂·x₂ + b is pure school algebra, and on its own it can only ever draw a straight line. The squish y = f(z) is what bends it. With none the neuron stays linear; pick ReLU, Swish, or GELU and the very same neuron becomes a curve.
