The Ring All-Reduce

Four GPUs each hold four chunks of one gradient. Every cell is a place-value number whose units digit is GPU 0’s contribution, whose tens digit is GPU 1’s, whose hundreds digit is GPU 2’s and whose thousands digit is GPU 3’s. The digit value names the chunk, so a cell reading 1101 is chunk 0 carrying every contribution except GPU 1’s. All four GPUs send to their right neighbour at the same time on every step.
