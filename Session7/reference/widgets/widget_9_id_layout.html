The Byte Budget

The grid has a fixed number of columns, so only the first pos_dim bytes of a token are ever seen. English spends one byte per character. Indic scripts spend three. The same window therefore holds very different amounts of language, and what falls off the end is dropped without a warning.

What happens past the edge

Two different words whose first bytes agree produce the same code, so they get the same vector for the whole of training. Nothing errors. The model simply cannot tell them apart, ever.
