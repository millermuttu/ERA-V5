Many attention layers also share keys, values and index results with later layers. DeepSeek places a lightweight copy of those shared components, called a shadow indexer, on each stage that reads them.

Each column is one stage running its forward pass (F) or backward pass (B) for one micro-batch.

The shared tensors reach the reader stages on the same point-to-point sends that carry activations between stages.
