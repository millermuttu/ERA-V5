The two bills

Attention creates two different long-context costs. First follow the saved attention history. Then compare how computation and memory grow.

First, the cache in plain language

When a model writes one token at a time, it keeps the earlier keys and values instead of calculating them again. That saved list is the KV cache. It belongs to one conversation and grows as that conversation grows.

token 1save K₁, V₁
token 2save K₂, V₂
token 3save K₃, V₃
…one pair per token

Two questions

Compute: how much work is needed to compare the tokens?

Memory: how much saved history must stay available for the conversation?

attention compute ≈ T²
KV-cache memory ≈ T
