V4 REALITY

The stage that was missing

Sangraha, our Indic web crawl, had ZERO deduplication. Near-identical pages were memorized instead of learned from. This machine — shingle, MinHash, band — is exactly the stage that was skipped.

HOW THE MACHINE WORKS
1
Shingle: slide a k-word window over each doc to build a set of overlapping k-grams.
2
MinHash: n hash functions; each slot keeps the minimum hash over the doc's shingles. P(slot matches) equals the true Jaccard.
3
Band: split n slots into b bands of r. Any exact band match makes the pair a candidate — no all-pairs comparison.
Shingles, MinHash signatures, and the LSH curve are all computed live in your browser. The FineWeb default shown (112 hashes = 14×8 rows, 5-word shingles, ~0.75 Jaccard) is from the FineWeb paper, arXiv:2406.17557.
