READ THE COLORS
Emails, the phone number and the IPv4 address are structured — a regex catches them exactly, with zero false positives. Names have no fixed shape, so they need the ML/NER layer. That layer is where mistakes appear: push aggressiveness up and it starts masking a place name that is not PII.
HOW REAL PIPELINES SPLIT IT

Two layers, two failure modes

Structured PII → regex (like Dolma): emails, phones, IPs match exact patterns, near-perfect precision. Names → ML/NER (e.g. Microsoft Presidio; verify tooling before you publish). Indic names raise false positives because place names, common words and given names overlap.

V4 REALITY

Dolma handled PII by regex at the document level. The Indic pipeline had no PII pass of its own — the very setting where a name model would have struggled most.
