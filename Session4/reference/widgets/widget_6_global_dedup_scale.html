The design decision

Local dedup does NOT produce a globally-deduplicated corpus. Only the central pass does. That is why it is a single owned machine sized for the whole corpus, not a step each student runs.

V4 reality

V4's Indic pipeline did local, per-source handling with no global dedup. The audit flagged it as wasted compute + memorization risk at scale.

Cross-shard matching and the index memory estimate are computed live. Duplicate detection runs a real FNV-1a hash over each document's text in JS; identical text yields an identical hash. Token counts are illustrative. Machine spec per the ERA V5 syllabus: large-memory instance (≥768 GB), high-throughput NVMe scratch, S3-attached, checkpoint-resumable, single owner plus backup.
